# Data

The raw dataset is not stored in this repository.

1. Download **Bank Marketing** from the UCI Machine Learning Repository:
   https://archive.ics.uci.edu/dataset/222/bank+marketing
2. Unzip it. Inside is `bank.zip`; unzip that too.
3. Copy **`bank-full.csv`** (45,211 rows, semicolon-separated) into this `data/` folder.

Citation: Moro, S., Rita, P. and Cortez, P. (2014) *Bank Marketing* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5K306. Licensed under CC BY 4.0.
